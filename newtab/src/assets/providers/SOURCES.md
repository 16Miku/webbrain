# Provider marks in the Companion banner

Copied from `src/chrome/icons/providers/` (Lobe Icons, MIT; see `SOURCES.md` there). The
`currentColor` fills are set to a fixed colour (white on a coloured tile, black for Kimi) because
the banner shows them as `<img>`, where `currentColor` has no text colour to follow.

Brand trademarks remain property of their owners; they only name the subscriptions WebBrain
Companion connects to WebBrain.
