文档 / 导出与已保存工作流
可迁移，也有边界

根据需要迁移的内容选择导出格式。

可读对话、诊断轨迹、设置备份和可复用工作流是四种不同文件。最安全的选择，是只导出完成目标所需的最少内容。

应该使用哪种导出？

目标命令结果
保存侧边栏中可见的对话/export便于阅读的 Markdown 对话记录。
调试已记录的代理运行/export --traces包含模型回复、工具调用、参数和结果的 Markdown。
备份或迁移设置/export --configwebbrain-config/1 JSON 快照。
迁移一个可复用自动化/workflow --export <id>经过清理的 webbrain-workflow/1 JSON 定义。
配置导出包含明文密钥

设置快照可能包含提供商 API 密钥、个人资料、用户记忆、自定义技能和权限选择。请像密码备份一样保存，切勿将其附加到公开 issue。

对话与轨迹 Markdown

/export 会保存侧边栏当前显示的消息，并记录导出时的 WebBrain 版本。该文件用于阅读，不能导回 WebBrain。

/export --traces 使用当前对话的本地轨迹记录，可能包含提示词、模型输出、URL、工具参数和工具结果。此 Markdown 文件不包含截图。如果某次运行时没有开启轨迹记录，之后无法补建该次轨迹。

准备提交错误报告？

优先使用对话导出。只有在需要工具级细节时才使用轨迹导出；分享前都应检查个人信息。

备份设置

  1. 输入 /export --config。
  2. 安全保存下载的 webbrain-config-….json。
  3. 使用 /import --file 恢复，或把 JSON 粘贴在 /import 后。

快照包含可迁移的设置值，但不包含对话、轨迹、计划任务、用量计数、累计支出，也不包含绑定设备的 Cloud Sync 会话和设备 ID。

schema 字段用于识别兼容性。WebBrain 当前导出并接受 webbrain-config/1。

迁移已保存工作流

  1. 开启轨迹记录并成功完成任务。
  2. 用 /workflow --save <名称> 保存。
  3. 运行 /workflow 查找 ID。
  4. 用 /workflow --export <id> 下载。
  5. 在另一套 WebBrain 中使用 /workflow --import --file。

可移植工作流不是原始轨迹。WebBrain 会删除旧元素引用、CSS 选择器、点击坐标、URL 查询字符串和片段，以及曾经输入的字段值。输入值会变成参数，在每次运行时于本地重新收集。

文件保留语义化目标描述、来源站点和路径范围，因此 WebBrain 可以重新查找当前元素，并在匹配不明确时安全停止。正常的执行模式权限、提交确认和结果验证仍然生效。

导入会创建副本

WebBrain 会分配新的本地 ID 和时间戳，不会覆盖现有工作流。可移植工作流文件上限为 1 MiB。

分享前检查

文件至少检查
对话 Markdown消息和系统提示。
轨迹 Markdown 或轨迹页 JSON提示词、URL、参数、结果及内嵌截图。
设置 JSON除非主动删除了所有密钥和隐私值，否则不要分享。
工作流 JSON名称、来源元数据、网站来源和路径范围、目标标签及步骤意图。

完整字段和兼容规则见技术格式参考（英文）。
