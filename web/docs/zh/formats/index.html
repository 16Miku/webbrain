文档 / 导出与已保存工作流
可迁移，也有边界

根据需要复用的内容选择导出格式，或示教一个工作流。

可读对话、诊断轨迹、设置备份和可复用工作流是不同类型的产物。最安全的选择，是只导出完成目标所需的最少内容；如果你已经熟悉步骤，示教模式可以从一次手动演示中学习。

应该使用哪种导出或工作流方式？

目标命令结果

设置快照可能包含提供商 API 密钥、个人资料、用户记忆、自定义技能和权限选择。请像密码备份一样保存，切勿将其附加到公开 issue。

对话与轨迹 Markdown

/export 会保存侧边栏当前显示的消息，并记录导出时的 WebBrain 版本。该文件用于阅读，不能导回 WebBrain。

/export --traces 使用当前对话的本地轨迹记录，可能包含提示词、模型输出、URL、工具参数和工具结果。此 Markdown 文件不包含截图。如果某次运行时没有开启轨迹记录，之后无法补建该次轨迹。

准备提交错误报告？

优先使用对话导出。只有在需要工具级细节时才使用轨迹导出；分享前都应检查个人信息。

备份设置

  1. 输入 /export --config。
  2. 安全保存下载的 webbrain-config-….json。
  3. 使用 /import --file 恢复，或把 JSON 粘贴在 /import 后。

快照包含可迁移的设置值，但不包含对话、轨迹、计划任务、用量计数、累计支出，也不包含绑定设备的 Cloud Sync 会话和设备 ID。

schema 字段用于识别兼容性。WebBrain 当前导出并接受 webbrain-config/1。

通过演示学习

亲自操作一次，教会 WebBrain 一个工作流

当你熟悉浏览器操作步骤，又不想先让代理完成一次带轨迹的运行时，可以使用示教模式。演示仅限当前标签页，最终会编译成与 /workflow --save 相同、带安全保护的 webbrain-workflow/1 格式。

  1. 打开起始页面。使用普通 http(s) 页面，并停止当前占用该标签页的代理运行。
  2. 开始示教。输入 /teach --start <名称>，页面上会出现紫色的 WebBrain Teach 指示器。
  3. 手动完成工作流。在同一标签页中，按可复用流程执行可信点击、完成字段输入、切换复选框或单选按钮、用 Enter 提交并进行导航。
  4. 按需查看进度。输入 /teach，查看当前工作流名称和已捕获操作数。
  5. 编译并保存。输入 /teach --end，再打开 /workflow 运行、重命名、导出或删除学到的工作流。
输入值绝不会被学习

页面捕获代码只记录字段的语义身份，不读取字段内容。每个完成的字段都会变成运行时参数；以后运行工作流时，WebBrain 会在本地重新询问当前值。

捕获边界

  • 只捕获顶层页面中的可信操作；WebBrain 自己执行的操作不会进入示教记录。
  • 会话会跟随同一标签页中的导航，最多记录 100 个规范化操作。
  • 示教模式与自动代理运行不能同时占用同一标签页。启动代理任务前，请先用 /teach --end 结束示教。
  • 不支持或不安全的目标会被跳过；保存结果会显示警告，重放时仍要求语义目标匹配唯一明确。
  • 即使无法编译出工作流，/teach --end 也会关闭临时示教会话；请修正页面或演示过程后重新开始。

从轨迹创建，再迁移已保存工作流

示教模式适合手动演示。如果代理已经在开启轨迹记录的情况下成功完成任务，也可以直接保存那次执行：

  1. 开启轨迹记录并成功完成任务。
  2. 用 /workflow --save <名称> 保存。
  3. 运行 /workflow 查找 ID。
  4. 用 /workflow --export <id> 下载。
  5. 在另一套 WebBrain 中使用 /workflow --import --file。

可移植工作流不是原始轨迹或示教会话。WebBrain 会删除旧元素引用、CSS 选择器、点击坐标、URL 查询字符串和片段，以及曾经输入的字段值。输入值会变成参数，在每次运行时于本地重新收集。

文件保留语义化目标描述、来源站点和路径范围，因此 WebBrain 可以重新查找当前元素，并在匹配不明确时安全停止。正常的执行模式权限、提交确认和结果验证仍然生效。

导入会创建副本

WebBrain 会分配新的本地 ID 和时间戳，不会覆盖现有工作流。可移植工作流文件上限为 1 MiB。

分享前检查

文件至少检查
对话 Markdown消息和系统提示。
轨迹 Markdown 或轨迹页 JSON提示词、URL、参数、结果及内嵌截图。
设置 JSON除非主动删除了所有密钥和隐私值，否则不要分享。
工作流 JSON名称、来源元数据、网站来源和路径范围、目标标签及步骤意图。

完整字段和兼容规则见技术格式参考（英文）。
