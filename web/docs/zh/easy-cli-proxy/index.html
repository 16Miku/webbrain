独立的本地兼容方案

使用账户而不是 API 密钥，但不要忽视信任边界。

EasyCLIProxyAPI 可以把支持的提供商账户暴露为一个本地 OpenAI 兼容端点。WebBrain 能使用该端点，但不会开发、审计、分发或认可这个代理程序。

最后核验：2026 年 8 月 26 日 · EasyCLIProxyAPI v0.2.62

这是一个能够访问 OAuth 凭据的第三方可执行程序。

并非由 WebBrain 开发、托管、审计或担保

EasyCLIProxyAPI 会管理提供商登录信息、本地凭据、另行安装的 CLIProxyAPI 核心及其自身更新。请审查源代码和当前版本，只从上游仓库下载，并在上游提供摘要时核对发行文件。WebBrain 无法检查未来的上游构建会执行什么操作。

使用本地代理并不代表推理也在本地完成。网页上下文和提示词仍会发送到代理所选的提供商账户。提供商规则可能变化；某个 OAuth 流程能够运行，不代表提供商允许所有第三方客户端使用它。

  • OpenAI：ChatGPT 订阅与 API 计费是两个独立产品。请查看订阅与 API 的区别以及当前使用条款。
  • Anthropic：其消费者条款限制通过 API 密钥或其他明确许可的接口之外的自动化或非人工访问。请查看当前消费者条款。
  • Google：Gemini CLI 条款说明，其 OAuth 身份验证不得用于第三方工具或服务。请查看当前 Gemini CLI 条款。
  • Kimi 和 xAI：上游提供 OAuth 只代表技术能力，并不代表获得许可或保证兼容。登录前请检查与你的产品、套餐、地区和账户对应的条款。

本指南介绍的是兼容性配置，不构成法律建议。账户、数据和合规决定仍由你负责。

配置

连接本地端点

  1. 检查并安装上游程序。从 GitHub 发行页面下载 EasyCLIProxyAPI。在版本管理中安装匹配的 CLIProxyAPI 核心。
  2. 把代理限制在回环地址。监听地址保持为 127.0.0.1，关闭局域网访问，绝不要转发端口 8317。用高强度随机值替换简短或默认的客户端密钥；根据版本不同，相关控件可能位于高级设置或 API 访问中。
  3. 只授权你确实要使用的账户。打开 OAuth，选择 Codex、Claude、Antigravity、Kimi 或 xAI，然后在提供商页面完成登录。如果提供商展示了你不接受的条款或权限，请立即停止。
  4. 启动核心并复制 OpenAI 兼容 URL。在首页启动运行时并复制 OpenAI 端点。常见默认值是 http://127.0.0.1:8317/v1；应以当前运行版本显示的值为准。
  5. 打开 WebBrain 设置 → 提供商。搜索本地 OpenAI 兼容代理。粘贴服务器 URL 和代理客户端密钥，而不是提供商的 OAuth 令牌。
  6. 加载并选择模型。点击加载模型，选择代理暴露的模型，填写真实上下文窗口；只有该模型确实接受图像时才启用视觉。
  7. 保存、测试，再启用。运行测试连接并确认出现绿色成功结果，然后再把它设为聊天提供商。先在非敏感内容上使用询问模式测试。
不要使用 0.0.0.0、局域网 IP、隧道或公开反向代理

本地客户端密钥不是安全的互联网公开认证系统。任何获得密钥的进程都可以通过已登录的提供商账户发送请求。

按症状排查问题

症状可能原因检查方法
连接被拒绝CLIProxyAPI 核心未启动或端口已改变。启动运行时，刷新首页，然后重新复制显示的 OpenAI URL。
未授权WebBrain 中的密钥与代理客户端密钥不一致。重新复制本地客户端密钥。绝不要把上游 OAuth 令牌粘贴到 WebBrain。
没有加载到模型OAuth 未完成、账户未暴露兼容模型，或上游支持已经变化。检查 OAuth/账户状态和 EasyCLIProxyAPI 日志，然后查看当前发行说明。
文本可用但图像失败所选模型别名不接受图像输入。关闭视觉，或选择代理报告为支持视觉的模型。
配额或账户错误上游账户、套餐、地区或提供商政策拒绝了请求。停止重试，直接检查提供商账户，并在可用时改用官方 API 密钥。
更新后模型或行为异常桌面应用、核心、插件或提供商协议发生变化。比较版本、查看发行说明，然后重新运行“加载模型”和“测试连接”。

WebBrain 明确不会做的事

  • 不会捆绑、启动、更新或验证 EasyCLIProxyAPI 或 CLIProxyAPI。
  • 不会接收或管理上游 OAuth 刷新令牌。
  • 不会承诺消费者订阅包含类似 API 的访问或自动化访问权限。
  • 不会绕过提供商配额、地区限制、账户审查或条款。
  • 不会让远程托管的推理变成私密或设备端推理。
