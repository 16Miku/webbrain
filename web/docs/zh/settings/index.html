不再猜测设置含义

知道该改什么，也知道什么可以不动。

从侧边栏齿轮或浏览器扩展选项打开设置。聊天模型及其辅助模型有单独的提供商页面：在侧边栏模型菜单中选择更多…，或点击设置页顶部的“提供商”链接即可打开。网站权限也有单独的页面：在麦克风旁边的 ⚠ 菜单中选择“管理网站权限”即可打开。大多数人主要使用“通用”、提供商和权限；其他标签页用于解决特定问题。

适合大多数人的默认值

控制项推荐值原因
执行前计划尝试计划有计划时使用；如果规划器格式化失败，安全回退到只读轮次。
计划审查低于置信度阈值时停止不确定的计划暂停，可靠计划可继续。
审查阈值90%在监督与流畅度之间较保守的平衡。
最大代理步骤130足够处理多步骤工作；出现重复时仍应手动停止。
LLM 请求超时120 秒云模型通常更快，大型本地模型启动可能更慢。
自动截图导航时代理打开页面后截一张图，而不是每次点击或输入后都截图。需要视觉模型检查每个操作时再选“状态变化时”。
云端费用额度每个会话 $10，总计 $10付费模型调用的机械停止点，可在“预算”中调高或调低。
计划任务关键操作确认开启无人值守任务仍会在关键操作前暂停。
权限闸门开启首次在网站执行特定操作前询问，并记住你的明确选择。侧边栏输入框中麦克风旁边的 ⚠ 按钮也可以切换它。
决策模型自动无需设置。Compass VLD Tiny v5 下载完成后用它做完成检查，只下载了 D1 时使用 D1（两者都未下载且 WebBrain Cloud 激活时使用 Compass 的托管决策模型），其他情况下不使用决策模型。
浏览器内视觉模型自动Compass VLD Tiny v5 下载完成后用它读取截图（只下载了 Ternary Bonsai 2 2B Vision 时用后者），且仅在聊天模型无法看图时使用。
日常使用

通用：代理如何行动

外观和下载位置只影响使用体验；下面的控制项会改变代理的工作方式：如何计划、何时由你审查、截取哪些截图。语言和缩放在侧边栏中选择，这里不再重复。

尝试计划适合日常使用；严格计划会在无法生成有效计划时取消任务；关闭会省去一次规划调用，但也失去计划审查节点。当“自动”为某条消息选择 Act 或 Dev，并确定它是简短、直接的任务（例如打开页面、搜索、填写并提交一个表单）时，尝试计划会跳过完整计划，只做快速的意图检查。包含多个目标、大量条目、多个网站、定时执行，或付款、删除等有风险步骤的任务仍会生成计划；计划审查设为始终询问时，每个 Act 或 Dev 轮次也都会生成计划。

自动截图默认为导航时：代理打开页面后截一张图，让视觉模型看到它到达了哪里。状态变化时还会在点击、输入等改变页面的操作后截图，图像令牌消耗更多；每一步在每次工具调用后截图；关闭只在你要求时截图。

标签栏下方的搜索框会同时搜索“通用”“预算”“CAPTCHA”和“高级”（无论你当前在其中哪个标签页），并把每个结果显示在所属标签页名称下。显示结果时，不会把任何标签页标记为当前标签页。点击结果上方的标签页名称即可打开该标签页，也可以在标签栏中选择标签页；两种方式都会结束搜索。清空搜索也会结束搜索，并回到你原来所在的标签页。

限制

预算：单个任务能走多远

“预算”把所有关于花费、等待和工作量的限制集中在一个标签页：云端费用额度、问题等待你回答的时间、步骤上限、模型请求超时和截图的图像预算。

设置默认值限制什么
云端费用会话额度$10.00单个对话中云端和路由模型调用的估算花费。达到额度后，WebBrain 会在下一次调用前停止。
云端费用总额度$10.00所有对话的估算总花费。标签会显示已花费金额，例如 $0.00 / $10.00；重置花费会重新开始计数。
澄清超时60 秒问题卡片等待你回答的时间，超时后 WebBrain 自行作答。滑块两端分别是“立即”和“关闭”。
问题超时时完成任务超时后的答案是继续推进任务，还是选择更安全的做法。
代理最大步骤数130一条消息中的工具调用步骤，不是聊天消息数。
LLM 请求超时120 秒等待模型开始响应的时间。
图像预算自动细节、每轮不限、1568 px每轮最多向视觉模型发送多少张截图，以及截图尺寸。

步骤上限越高，长流程越有机会完成和恢复，但也可能消耗更多令牌。请求超时只限制模型开始响应前的等待时间，不会中断已经开始流式输出的响应。

无限步骤不等于更可靠

∞ 只会移除机械停止点，不会让模型更不容易循环。除非你正在全程监督长任务，否则保留有限上限。

按需使用

记忆：决定哪些信息长期保留

  • 加密云同步面向 WebBrain Compass 会员；支持的提供商密钥、个人资料和记忆会在上传前用同步密码加密。聊天历史与 OAuth 登录不会同步。
  • 个人资料自动填充以明文保存在当前浏览器配置中，启用后会发送给当前模型提供商。
  • 用户记忆保存稳定偏好；/memory --add 会立即保存，自动学习是可选项。
不要把记忆当作密码管理器

不要在个人资料或用户记忆中存放密码、API 密钥、令牌、恢复码等秘密。

信任决定

技能：附加指令与工具

技能可以把指令加入系统提示；含 webbrain-tools 清单的技能还可暴露 HTTP 或下载任务工具。导入本身就是信任决定，只导入你信任的来源。

“技能”标签页先列出已启用的技能，再列出可以启用的内置技能。点击添加技能可打开表单，从网址导入技能或粘贴技能文本；对已启用的技能点击编辑，会在同一表单中载入该技能。

按需使用

CAPTCHA：求解服务账户

CAPTCHA 标签页为 CapSolver、2Captcha、CapMonster Cloud、SolveCaptcha、Anti-Captcha、NopeCHA 和 NoneCap 各提供一张卡片。输入密钥会勾选启用；你也可以取消勾选并保留密钥。保存后生效，测试余额不会自动启用服务。

展开每个服务的高级设置可修改权重，默认依次为 100 至 94。可同时启用多个服务，兼容的服务按权重从高到低尝试。错误或超时后的回退可能产生多次费用。hCaptcha 使用 NopeCHA 或 NoneCap；其他类型需要相应服务支持和页面参数。请阅读完整 CAPTCHA 指南（英文）。

专家标签页

高级：带着明确目的再打开

“高级”现在是一个独立的标签页。用搜索框可以直接跳到某个控制项；它会同时搜索“高级”“通用”“预算”和“CAPTCHA”。

设置通常保持何时修改
记录轨迹关闭比较模型或诊断运行，并接受本地存储。一个开关会连同完整请求细节（提示、消息、工具定义和结果）一起记录每次运行。
截图回退视觉模型可用时开启DOM 读取遗漏图表、画布或视觉内容。
截图打码关闭希望在截图发送给视觉模型前，先模糊表单字段和看起来像邮箱或电话号码的文字。这是尽力而为的保护，不是保证。
站点适配器开启调试令牌使用或禁用站点专用提示。
API 变更观察器关闭研究重复 UI 操作与 API 快捷建议。
严格的机密处理个人日常使用时关闭屏幕共享或导出轨迹，不希望凭据被引用。
允许代理访问本地网络关闭必须访问 localhost、内网或私有地址。
日常使用

提供商：选择当前模型

提供商是一个独立的页面。在侧边栏模型菜单中选择更多…，或点击设置页顶部的提供商链接即可打开。第一个标签页 LLM 列出聊天提供商，其他标签页是下面介绍的辅助模型。

一次只有一个提供商处于活动状态。正确顺序是 保存 → 测试连接 → 设为活动。

本地服务器地址、上下文窗口和提示层级见提供商与模型。

按需使用

视觉、语音与决策模型：支持主要代理

在提供商页面的 LLM 标签页中选择主要对话模型。该页面的其他标签页是可选的辅助模型：视觉、语音、生成（图像和视频）、决策和 SafeSocial。配置它们不会改变当前提供商。

视觉和决策模型默认都是自动。在支持硬件 WebGPU 的 Chrome 中，自动模式会在 Compass VLD Tiny v5（约 2.2 GB，在本机运行）下载完成后使用它，下载前不使用；WebBrain Cloud 激活时，在它下载完成前由 Compass 的托管决策模型回答决策。安装页上的下载本地模型按钮、提供商 → WebGPU、视觉卡片和末日模式下载的都是同一个模型，一次下载即可同时用于聊天、截图和决策。

视觉

选择由谁读取截图。保存了 OpenAI 兼容端点时，所有截图都交给它，当前提供商继续负责规划和工具调用。没有端点时，当前模型若能看图就自己读取截图；不能看图时，由浏览器内视觉模型读取（仅 Chrome）。全部保持默认即可让当前提供商处理视觉。截图限制在“设置 → 预算”中，截图打码在“设置 → 高级”中。

浏览器内视觉模型有五个选项：

  • 自动（默认）：Compass VLD Tiny v5 下载完成后使用它，只下载了 Ternary Bonsai 2 2B Vision 时使用后者，下载前保持关闭。
  • Compass VLD Tiny v5：约 2.2 GB，同一个模型也能聊天和回答决策问题。
  • Ternary Bonsai 2 2B Vision：约 1.45 GB，同一个模型也能聊天。
  • WebBrain VL 2 450M：约 810 MB，只用于视觉。首次下载会征求你的同意并检查 WebGPU。
  • 关闭：不使用浏览器内视觉模型。

更改选项不会自动下载任何内容，请使用卡片上的下载按钮。任务从不等待下载完成；在浏览器内读取的截图不会离开你的设备。Firefox 没有浏览器内视觉模型。

语音

为录音配置 Whisper 兼容端点。留空时依次尝试已配置的 OpenAI、Groq、LM Studio、llama.cpp。

生成

为图像和视频生成工具连接 fal.ai、OpenRouter、ComfyRouter 或本地 ComfyUI 服务器。默认不配置任何服务。

决策

决策模型是一个小而快的模型，负责回答智能体的是非题和选择题，例如“这个任务完成了吗？”，这样聊天模型就不必处理这些问题。它从不规划、点击或输入。可选三种模式：

  • 自动（默认）：无需设置。在 Chrome 中，Compass VLD Tiny v5 下载完成后，用它检查侧边栏任务以及计划监控和计划任务是否真正完成；只下载了 D1 时由 D1 检查。当 WebBrain Cloud（Compass）是你的聊天提供商时，在其中一个下载完成前由 Compass 的决策模型回答。其他情况下不使用决策模型。卡片会显示当前使用的是哪个。
  • 开启：所有决策都使用你配置的提供商：OpenRouter、TypeSafe、本地 System One 服务器、D1，或 Chrome 中的浏览器内聊天模型。所有决策默认开启。展开选择哪些决策使用它可以单独关闭某些决策（验证完成、验证计划监控、验证计划任务完成、快速分类、快速浏览器操作（实验性））并设置阈值。
  • 关闭：从不使用决策模型，包括 Compass 的决策模型。聊天模型仍会检查任务是否完成。

切换模式立即生效；“开启”模式下的提供商字段需要点击保存。测试连接只用固定示例数据发送一次请求。重置会回到自动模式并删除已保存的决策密钥。云端决策提供商会收到有限的任务与页面数据，可能产生费用；严格秘密模式会禁用决策模型。在这些模式推出前已开启决策外包的配置会按“开启”继续工作，并保留原有开关。

SafeSocial

可选的本机 Instagram 图片分类器。在你开启前保持关闭；模型只下载一次，并在浏览器内运行。

日常安全

权限：WebBrain 可以在哪里做什么

权限是一个独立的页面。保持“执行重要操作前询问”开启。你在侧边栏选择“始终允许”时，WebBrain 会记录一个具体网站的具体能力，并在权限页面中列出。每条永久授权都对应一个明确的“网站 + 能力”组合；允许点击并不自动允许输入、下载、上传、执行 JavaScript 或安排任务。

侧边栏里也有同一个开关：点击输入框中麦克风旁边的 ⚠ 按钮即可打开，里面还有前往权限页面的链接。提示关闭期间，该按钮显示为橙色并带一个圆点。在这里关闭提示不会批准已经在等待的权限卡片，那张卡片仍需你自己回答。
