# Third-party models

This repository does not redistribute model weights.

- DeepSeek V4 Flash weights and code are obtained from `deepseek-ai/DeepSeek-V4-Flash`.
- The H200 training profile uses the weight-only FP8 repack from
  `sgl-project/DeepSeek-V4-Flash-FP8`.
- MoonViT code and weights are obtained from `moonshotai/Kimi-K2.6`.
- The A/B tower is obtained from `Qwen/Qwen3.6-27B`.

Review and comply with each upstream repository's license and acceptable-use terms before
downloading data or weights. Keep the exact model revision in experiment metadata.
